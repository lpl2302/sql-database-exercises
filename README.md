# SQL Database Exercises

A collection of SQL exercises completed while studying databases at the University of Oulu.

This repository demonstrates practical use of relational databases and SQL, including:

* `SELECT`, `WHERE`, and `ORDER BY`
* Filtering and `NULL` handling
* `DISTINCT`
* `JOIN` operations
* Self joins
* Aggregate functions
* `GROUP BY` and `HAVING`
* Subqueries
* Correlated subqueries
* `UNION`
* SQLite date functions
* `INSERT`, `UPDATE`, and `DELETE`

## Structure

### `01-select-filtering.sql`

Basic data retrieval, filtering, sorting, and handling missing values.

### `02-joins.sql`

Queries combining related tables using joins, including self joins.

### `03-subqueries.sql`

Queries using nested queries to filter or compare data.

### `04-aggregation.sql`

Aggregate functions such as `COUNT`, `SUM`, `AVG`, `MIN`, grouping, and `HAVING`.

### `05-data-modification.sql`

Examples of inserting, updating, and deleting relational data.

### `06-advanced-queries.sql`

More complex queries combining techniques such as `UNION`, date calculations, correlated subqueries, and multi-table relationships.

## About the exercises

The exercises were completed as part of database studies at the University of Oulu.

Original course exercises are provided through the University of Oulu Lovelace learning environment.

The descriptions in this repository have been shortened or paraphrased rather than reproducing the original exercise material.

The SQL queries are my own solutions.

Course database files and Moodle-only course materials are not redistributed in this repository.
